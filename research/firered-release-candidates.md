# FireRed release candidates

The local corpus contains eight byte-distinct identities: Japanese `BPRJ` revisions 0 and 1, English `BPRE` revisions 0 and 1, and German `BPRD`, French `BPRF`, Italian `BPRI`, and Spanish `BPRS` revision 0. Every input is 16 MiB and passed all shared GBA header checks.

All identities remain `candidate`. Header integrity is not independent retail provenance, and promotion to `verified` requires trusted external corroboration or a reproducible matching build. No identity is imported from the separate Decompilation project.

No ROM binary or byte extract is included.
