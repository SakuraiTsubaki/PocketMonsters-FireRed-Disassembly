# FireRed Pikachu sprite set

`bpr-j-rev0-retail` is the Japanese origin reference. For all 8 cataloged releases (Japanese, English, German, French, Italian, Spanish), the front, back, and palette entries are resolved from species tables anchored by the already verified Deoxys entry. Each LZ77 stream is decoded to a rendered PNG or JASC palette with compressed, decoded, and output hashes; no ROM bytes are published.
