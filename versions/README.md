# Version Baselines

The disassembly targets eight FireRed language/revision baselines.

| ID | Language / Region | Revision | Status |
|---|---|---|---|
| `jp_1_0` | Japanese | 1.0 | pending verification |
| `jp_rev1` | Japanese | Rev 1 | pending verification |
| `us_1_0` | English / USA | 1.0 | pending verification |
| `us_eu_rev1` | English / USA-Europe | Rev 1 | pending verification |
| `fr` | French | release baseline | pending verification |
| `de` | German | release baseline | pending verification |
| `it` | Italian | release baseline | pending verification |
| `es` | Spanish | release baseline | pending verification |

Exact cartridge metadata, ROM size, header fields, and cryptographic checksums will be populated from the project's read-only reference ROM set after direct verification.

Version-specific code, data, text, graphics, or layout changes should be isolated here rather than duplicating the entire shared source tree.
